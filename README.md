# VS Code Workflow Test

This project verifies my VS Code, Python virtual environment, and dependency setup for AI Engineering.

## What This Project Tests

- VS Code project setup
- Python virtual environment
- Package installation
- requirements.txt usage
- Git workflow

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
